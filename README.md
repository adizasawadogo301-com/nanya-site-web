# NANYA — Django

1. `python -m venv .venv`
2. Windows : `.venv\Scripts\activate`
3. `python -m pip install -r requirements.txt`
4. `python manage.py migrate`
5. `python manage.py createsuperuser`
6. `python manage.py runserver`

Ouvrir http://127.0.0.1:8000/ et /admin/.

À remplacer avant livraison : logo officiel, coordonnées, réseaux sociaux, vrais partenaires et réalisations. Les huit domaines suivent le cahier des charges fourni.
